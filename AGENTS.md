# Pull requests

- Follow [CONTRIBUTING.md](CONTRIBUTING.md). Use `(<type>) <Sentence-case summary>` for PR titles, for example `(fix) Add viewport-aligned rotation to Transform`. Use the same format for commit subjects that will become PR titles.
- Set the PR title explicitly when publishing. Before opening or updating a PR, validate the exact title and description with `PR_TITLE='<title>' PR_BODY_FILE='<body-file>' node scripts/check-pull-request.mjs`.
